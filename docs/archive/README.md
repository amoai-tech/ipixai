# Documentation archive

This directory preserves superseded plans, audits, migration notes, task snapshots, and design evidence that are no longer current iPix documentation.

## Rules

- Archive files are historical evidence, not implementation authority.
- Do not copy task status from archive files; check Linear.
- Do not implement package/API claims from archive files without re-verifying current code and installed types.
- Preserve the original directory structure so history and internal context remain easy to trace.
- Archived snapshots may contain historical local paths that no longer resolve; the CI link gate applies to current docs, not archived link graphs.

Current documentation starts at [`../README.md`](../README.md).
