## Wire contracts

### IPI-1110 · CLD-SIGN-001 — Sign Cloudinary Uploads for the Trusted Organization

Installed `generateSignatureCallback` **requires**:

```http
POST signatureEndpoint
{ "paramsToSign": { ... } }

→ { "signature": "<string>" }
```

Keep that wire shape. Server still:

1. auth + trusted org (never `body.org_id`)
2. brand (+ optional shoot) ownership
3. mint internal `asset_id` UUID
4. **override** security fields before `cloudinary.utils.api_sign_request`: `overwrite=false`, `type=authenticated`, `upload_preset`, `context`, `folder`/`public_id` as needed
5. reject client attempts to set those keys

Do **not** build custom uploader UI, multipart, or signature algorithms.

### IPI-1111 · CLD-WEBHOOK-001 — Mirror Cloudinary Uploads and Deletes into Supabase
