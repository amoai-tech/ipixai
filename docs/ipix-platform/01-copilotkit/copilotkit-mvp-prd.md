# CopilotKit MVP PRD

> Status: Placeholder — MVP scope to be consolidated from verified iPix product journeys.

## MVP outcome

Operators use CopilotKit as the interactive AI layer across real iPix workflows such as Brands, Shoots, CRM, and Campaigns, with structured review UI and explicit human decisions.

## MVP scope

- Domain-aware chat/context
- Structured GenUI cards
- Brand DNA review
- Shoot plan review/edit
- Approval/rejection interactions
- Shared editable state where proven useful
- Clear tool/workflow progress states
- Failure and recovery UX
- Accessibility for streaming and approvals

## Guardrails

- CopilotKit is the interaction layer, not the business database.
- Domain writes execute only after server-side authorization and approval.
- Do not make multi-agent orchestration an MVP dependency unless a real journey requires it.

## Acceptance evidence

Prove the user journey end-to-end with real tenant context, reload/reconnect, HITL, and durable read-back.
