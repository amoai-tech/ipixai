# Product Requirements

This page is the top-level requirements entry point for the curated iPix documentation.

## Source-of-truth rule

* Current code, runtime evidence, tests, and accepted architecture decisions describe what exists now.
* Product-area documentation describes durable requirements and user journeys.
* Linear owns live task status, blockers, assignees, and execution progress.

## Current product structure

Use [Product Sitemap](sitemap.md) for the canonical routes, product areas, and maturity status. Use [Documentation Index](index-docs.md) to find the maintained platform and domain documents.

Do not duplicate detailed feature requirements here. Add them to the relevant product-area document only after the current implementation has been verified.
